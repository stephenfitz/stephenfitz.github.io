Marvin Minsky on Perceptrons

Obviously linear separability is not a restriction of modern neural networks, which can learn arbitrarily continuous functions on compact subdomains of \( \mathbb{R}^n \) (assuming at least a single hidden layer and nonlinear activation neurons, as shown in the famous result known as the Universal Approximation Theorem). However, a widespread misinterpretation of perceptrons caused a long period of stagnation in neural network research, until their resurrection due to people like Hinton. Now Neural networks achieve state of the art results in all major areas of machine learning, beating advanced statistical models. This is known as the "deep learning revolution" of recent years, and it is just the beginning. New results come out every day, and it is an exciting field to be in. In order to understand neural networks, it is good to start with their ancestor - the perceptron. Its learning rule can be seen (up to a small difference) as stochastic sub-gradient descent on a "perceptron loss" function. Modern neural networks are trained using the back-propagation algorithm, which is also SGD on their loss functions. We will study increasingly more complex neural systems throughout this course. Perceptron is a basic building block of more advanced neural networks.

SVM

There is a classical machine learning algorithm inspired by perceptrons, known as Support Vector Machines, which extends to nonlinear decision boundaries and gives a unique solution (highest margin).

perceptron neuron

perceptron neuron

  • inputs are real numbers (often the first input is a constant set to 1.0, to account for the bias term)
  • the neuron computes a linear sum of inputs multiplied by weights
  • the weights form an internal state of the neuron (learned from data)
  • start with randomly initialized weights
  • the activation function returns a binary choice (-1 or 1)

perceptron neuron

  • first compute the weighted sum: \( z = \sum\limits_i{w_i x_i} = \mathbf{w}^\intercal \mathbf{x} \)
  • then pass it to the activation function: \[ y = \sigma(z) = \begin{cases} -1 & z\leq \theta \\ 1 & z> \theta \end{cases} \]
  • usually we include the threshold in a dummy input \[ y = \sigma(z) = \begin{cases} -1 & z\leq 0 \\ 1 & z> 0 \end{cases} \]

teaching a perceptron neuron (supervised learning)

We are given a dataset of examples \( D = \{ (x^{(1)}, t^{(1)}), (x^{(2)}, t^{(2)}), \dots, (x^{(n)}, t^{(n)}) \} \), where each x is an input (i.e. a vector of numbers representing a collection of inputs, which describe something), and each t is a label (representing the desired target output). This is called a training set.

The goal is to train the neuron to recognize inputs from some coherent set. The goal of training is to get your neuron to produce predictions that agree with the ground truth labels on the training set.

error(loss) function

\[ L_{\mathbf{w}}(\mathbf{x}^{(i)}, t^{(i)}) = max(0,−t^{(i)} \mathbf{w}^\intercal \mathbf{x}^{(i)}) \]

Think why this loss function makes sense.

learning rule

update the weights (component-wise: $i$) using each example label $t$, input $\mathbf{x}$ and predicted output $y$: \[ w_i^{\text{new}} \longleftarrow w_i^{old} + \eta (t - y) x_i \]

  • \( \eta \) is an arbitrarily chosen hyper-parameter called the learning rate
  • \( \mathbf{x} = \left( x_1, x_2, \dots, x_n \right) \) is the input to the neuron (one training example)
  • \( y = \sigma \left( \sum\limits_{i = 1}^{n}{w_i x_i} \right) \in \left\{ -1, 1 \right\} \) is the output (prediction) of the neuron for the given input ($\sigma$ is the perceptron activation/transfer function)
  • \( t \in \left\{ -1, 1 \right\} \) is the training set label for the given input (desired target output)

machine learning

This is our first example of a machine learning system (the predominant form of artificial intelligence). We will write a program that can learn from its experience, in order to become better at accomplishing perceptual tasks (classifying objects). In order to make our program learn we will build a single neuron inspired by one type of nervous cell found in animal brains. Although our program will simulate the learning process of just a single simple neuron (not an entire brain with complex neural structure as is done with modern deep learning systems), it is powerful enough to process various forms of perceptual input and capable of learning useful information from data.

We will then teach this neuron to become better at its task by training it on a dataset of examples. Afterwards, our neuron can clasiffy objects that it has not seen during training.

object classification

We will use our neuron as a base to peform supervised learning for a classification task of practical utility. We will write a Python program to train our neuron on a real dataset of examples sourced from a declassified US military program. Our code will accomplish a task involving decision making based on perceptual inputs:

  • INPUT: sonar waves bouncing of underwater objects
  • OUTPUT: was the object a mine?

the perceptron

We will implement the Perceptron learning algorithm - a precursor to modern neural networks. The perceptron algorithm was invented in 1957 by Frank Rosenblatt, while working on a grant from the Office of Naval Research. It was originally implemented in hardware costing millions of dollars in today's currency.

This was a military project funded by the the US Navy. Its applications included ballistic missile trajectory computation and the detection of sea mines.
The military was interested in classifying various types of naval mines vs other objects encountered in the ocean waters. For this project we will focus on a binary choice between one type of underwater mine vs a rock.
We will be given a dataset of sonar waves bouncing off two types of underwater objects: rocks and naval mines. Our task is to make predictions based on the returning wave, as to which objects it encountered.
This is a real dataset made public by the Navy. The waves were preprocessed and stored as sequences of sonar amplitudes.
