QUESTION 1

loop invariants

Consider the following algorithm which takes an array A of real numbers, indexed from 1 to n.


                    TestAlg(A)
                    ----------
                    n ← length(A)
                    for j ← 1 to floor(n/2) do
                        k ← n + 1 - j
                        A[j] ← A[j] + A[k]
                        A[k] ← A[j] - A[k]
                        A[j] ← A[j] - A[k]

bubblesort analysis

Bubblesort is an inefficient sorting algorithm that works by repeatedly swapping adjacent elements that are out of order.


                    BUBBLESORT(A, n)
                    ----------------
                    1:  for i ← 1 to n-1 do
                    2:      for j ← n downto i+1 do
                    3:          if A[j] < A[j-1] then
                    4:              exchange A[j] with A[j-1]

                    7:  end for
