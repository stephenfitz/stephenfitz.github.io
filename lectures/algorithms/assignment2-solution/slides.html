SOLUTION 2

  1. (a) \(f(n)+g(n)=\Omega(\max(f(n),g(n)))\) — Always true.
  2. (b) \(f(n)=\omega(g(n))\) and \(f(n)=O(g(n))\) — Never true (contradiction via limit).
  3. (c) \(f(n)=O(g(n)) \Rightarrow 2^{f(n)}=O(2^{g(n)})\) — Sometimes (true for \(f=n,\;g=n+1\); false for \(f=2n,\;g=n\)).

(A) PROOF (SKETCH)

\(f,g\) asymptotically nonnegative; for all \(n\), \(f(n)+g(n)\ge \max(f(n),g(n))\). Choose \(c_1=1\), \(n_0=1\) to obtain the \(\Omega\) bound.

(B) PROOF BY CONTRADICTION (SKETCH)

Assume both \(f=\omega(g)\) and \(f=O(g)\). Then \(\lim_{n\to\infty} \frac{f}{g}=\infty\) and \(\exists c_1,n_0: f\le c_1 g\) for \(n\ge n_0\). But then \(\lim \frac{f}{g}\le \lim c_1=c_1\), contradiction.

(C) COUNTEREXAMPLES

  • True case: \(f(n)=n,\; g(n)=n+1\) ⇒ \(2^{f}\le 2^{g}\cdot 2^{-1} = \frac{1}{2} 2^{g} \in O(2^{g})\).
  • False case: \(f(n)=2n,\; g(n)=n\) ⇒ \(f=O(g)\) fails for exponentials: \(2^{2n} = 2^n \cdot 2^n \notin O(2^n)\).

EXTRA SOLUTION

  • \(\displaystyle \frac{\ln\ln n}{n^2}\to 0 \Rightarrow \ln\ln n=o(n^2)\).
  • \(\displaystyle \frac{\ln^2 n\cdot n^2}{n^{1/2}}\to 0 \Rightarrow \ln^2 n=o(n^{-3/2})\) relative to \(n^{1/2}\) (hence \(\ln^2 n \ll n^{1/2}\)).
  • \((\sqrt{3})^{\log_3 n}=n^{1/2}\) since \(a^{\log_b n}=n^{\log_b a}\).
  • \(\displaystyle \frac{n^{1/2}}{n\lg^2 n}\to 0 \Rightarrow n^{1/2}=o(n\lg^2 n)\).
  • \(\displaystyle \frac{\ln^2 n}{n}\to 0\) and \(\frac{\ln n}{n^{1/2}}\to 0\).
  • \(4^{\log n}=n^2,\; \frac{n^2}{n^3}\to 0,\; \frac{\ln n}{n\ln\ln n}\to 0\).

final ordering (from smallest to largest):

\(\ln n \;<\; \ln^2 n \;<\; n^{1/2} = (\sqrt{3})^{\log_3 n} \;<\; n\lg^2 n\)

\(\;<\; [\,n^2 = 4^{\log n}\,] \;<\; n^3 \;<\; n\ln\ln n\)

Equivalence classes:

\([\,n^{1/2},\; (\sqrt{3})^{\log_3 n}\,]\), \([\,n^2,\; 4^{\log n}\,]\)
