QUICKSORT

  • Proposed by C. A. R. Hoare (1962)
  • Divide–Conquer; sorts in place; highly practical with tuning
  • Key subroutine: linear-time partition
  1. Divide: Partition array around pivot x so that lower ≤ x ≤ upper
  2. Conquer: Recursively sort subarrays
  3. Combine: Trivial

Goal: Linear-time partition and good (often balanced) splits

partition

Maintain regions: ≤ x, unknown, ≥ x

Indices: p (start), i (last ≤ x), j (scan), q (end) 


PARTITION(A, p, q)
  x ← A[p]
  i ← p
  for j ← p+1 to q:
    if A[j] ≤ x:
      i ← i + 1
      exchange A[i] ↔ A[j]
  exchange A[p] ↔ A[i]
  return i

QUICKSORT

Recursively sort partitions returned by partition; initial call on full array.


QUICKSORT(A, p, r)
  if p < r:
    q ← PARTITION(A, p, r)
    QUICKSORT(A, p, q−1)
    QUICKSORT(A, q+1, r)

# Initial call: QUICKSORT(A, 1, n)

WORST-CASE ANALYSIS

  • Occurs for sorted or reverse-sorted inputs with bad pivots (min/max)
  • Recurrence: \(T(n)=T(0)+T(n-1)+\Theta(n)\) \(= T(n-1)+\Theta(n)\)
  • Recursion depth \(h=n\); total work \(\Theta(n^2)\)

BEST / ALMOST-BEST CASE

  • Balanced splits: \(T(n)=2T(n/2)+\Theta(n)=\Theta(n\log n)\)
  • Even 9:1 or 99:1 constant-proportion splits give \(\Theta(n\log n)\)
  • Depth \(\Theta(\log n)\), \(O(n)\) work per level ⇒ \(\Theta(n\log n)\)

In fact, any constant split gives \(\Theta(n\log n)\)!

Suppose we alternate lucky (roughtly equal) and unlucky (min/max) splits.

$$ L(n) = 2U(n/2) + \Theta(n) $$ $$ U(n) = L(n - 1) + \Theta(n) $$

$$ L(n) = 2(L(n/2 - 1) + \Theta(n/2)) + \Theta(n) $$ $$ = 2L(n/2 – 1) + \Theta(n) \implies L(n) \in \Theta(n\log n)$$

RANDOMIZED QUICKSORT

  • Choose pivot uniformly at random
  • Running time independent of input order; avoids adversarial worst-case
  • Expected \(\Theta(n\log n)\)
  • excellent general-purpose sorter
  • often >2× faster than merge sort in practice
  • benefits from careful code tuning

COMPARISON SORTING

$a = [a_1, a_2, a_3] = [9, 4, 6]$

Any comparison sort on n elements generates a decision tree with ≥ n! leaves

Binary tree of height h has ≤ \(2^h\) leaves ⇒ \(n! ≤ 2^h\)

Stirling approximation to the factorial gives \(h \ge \lg(n!) \ge \lg (\frac{n}{e})^n \ge n\lg n - n\lg e = \Omega(n\lg n)\)

Corollary: Heapsort and mergesort are asymptotically optimal!
