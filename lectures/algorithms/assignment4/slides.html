QUESTION 1

Given an array of integers nums and an integer target, return the indices of the two numbers such that they add up to target. You may assume that each input would have exactly one solution, and you may not use the same element twice.

Hint: You may solve this question using a hash table.

EXAMPLE

Input: nums = [2, 7, 11, 15], target = 9

Output: [0, 1]

  • Explanation: nums[0] + nums[1] = 2 + 7 = 9
  • The indices of the two numbers are [0, 1].

QUESTION 2

In class, we discussed heapify up and heapify down operations for a Max-Heap, where:

  • Heapify up "floats" a larger key to restore the heap property.
  • Heapify down "sinks" a smaller key to restore the heap property.

Your task is to implement the heapify up and heapify down functions for a Min-Heap (binary heap with parent.key ≤ child.key, root has the minimum key).

QUESTION 3

You are given an array of intervals where intervals[i] = [start_i, end_i] represents the start and end times of a meeting. Return the minimum number of meeting rooms required to schedule all the meetings without any overlap.

Hint: You may need a min-heap to efficiently manage meeting end times.

EXAMPLE

Input: intervals = [[0, 30], [5, 10], [15, 20]]

Output: 2

  • Meeting [0, 30] conflicts with [5, 10].
  • You need at least two rooms: one for [0, 30] and another for [5, 10] and [15, 20].
