MINIMUM SPANNING TREES

A spanning tree of a connected graph \(G=(V,E)\) is a subset of edges that connects all vertices and contains no cycles.

THE MINIMAL SPANNING TREE (MST) PROBLEM

Input: Connected, undirected \(G=(V,E)\) with weight function \(w:E\to\mathbb{R}\) (assume distinct weights for simplicity).

Output: A spanning tree \(T\subseteq E\) minimizing total weight

\[ w(T)=\sum_{(u,v)\in T} w(u,v). \]

OPTIMAL SUBSTRUCTURE

Let \(T\) be an MST of \(G\). Remove any edge \((u,v)\in T\); the tree splits into two subtrees \(T_1\) and \(T_2\) on vertex sets \(V_1\) and \(V_2\).

Theorem: \(T_1\) is an MST of the subgraph \(G_1=(V_1,E_1)\) induced by \(V_1\) (and similarly for \(T_2\)).

Weight decomposition: \[ w(T)=w(u,v)+w(T_1)+w(T_2). \]

Cut-and-paste: If \(T_1'\) were a lower-weight spanning tree of \(G_1\) than \(T_1\), then \(\{(u,v)\}\cup T_1'\cup T_2\) would be a lighter spanning tree of \(G\), contradicting optimality of \(T\).

GREEDY-CHOICE PROPERTY

Theorem: Let \(T\) be an MST of \(G=(V,E)\), and let \(A\subset V\). If \((u,v)\) is the least-weight edge crossing the cut \((A, V\setminus A)\), then \((u,v)\in T\).

This property underpins greedy MST algorithms.

PRIM'S ALGORITHM

  • Grow a tree from an arbitrary start vertex.
  • Maintain, for each outside vertex, the lightest edge to the current tree (a key in a priority queue).
  • Repeatedly add the minimum-key vertex and its connecting edge.

Initialize Q ← V (min-priority queue by edge)
for v in V: key[v] ← +∞; parent[v] ← NIL
choose arbitrary s ∈ V; key[s] ← 0
while Q not empty:
  u ← EXTRACT-MIN(Q)
  for v in Adj[u]:
    if v ∈ Q and w(u,v) < key[v]:
      key[v] ← w(u,v) # DECREASE-KEY on v
      parent[v] ← u
# MST is {(v, parent[v]) : v ≠ s}

KRUSKAL'S ALGORITHM

  • Sort edges by weight; scan from lightest to heaviest.
  • Add an edge if it connects two different components (use disjoint sets).
  • Stop when \(|V|-1\) edges added.

Running time: \(O(|E|\log|V|)\) with efficient union-find.

Summary

  • MSTs have optimal substructure and admit safe greedy choices.
  • Prim grows a tree; Kruskal grows a forest.
  • Both rely on the cut property; correctness via cut-and-paste arguments.

DIJKSTRA'S ALGORITHM

Let a digraph be denoted by \(G=(V,E)\) with edge-weight function \(w:E\to\mathbb{R}\). For a path \(p = v_1 \to v_2 \to \cdots \to v_k\), its total weight is

$$w(p)=\sum_{i=1}^{k-1} w(v_i, v_{i+1})$$

SHORTEST PATH

A shortest path from \(u\) to \(v\) is any path attaining the minimum total weight. Define

$$\delta(u,v) = \min\{\, w(p) : p \text{ is a path from } u \text{ to } v \,\},$$

with the convention that \(\delta(u,v)=+\infty\) if no path from \(u\) to \(v\) exists.

OPTIMAL SUBSTRUCTURE

Theorem. Any subpath of a shortest path is itself a shortest path (between its endpoints).

Idea of proof: a cut-and-paste argument — if a subpath were not shortest, replacing it with a better one would improve the original path, contradicting optimality.

TRIANGLE INEQUALITY

Theorem. For all \(u,v,x \in V\),

$$\delta(u,v) \le \delta(u,x) + \delta(x,v).$$

Proof sketch: concatenating any \(u\!\to\!x\) path with any \(x\!\to\!v\) path yields a \(u\!\to\!v\) path; minimizing both sides gives the inequality.

DIJKSTRA'S ALGORITHM

Goal: from a single source \(s\), compute \(\delta(s,v)\) for all \(v\in V\) assuming \(w(e)\ge 0\) for every edge.

High-level idea: a greedy expansion from \(s\) maintaining a set \(S\) of vertices whose distances are finalized; repeatedly extract the minimum tentative distance and relax outgoing edges.

GREEDY INVARIANT

Maintain a distance estimate \(d[v]\) for each vertex and a finalized set \(S\). At each step, the vertex \(u\notin S\) with smallest \(d[u]\) is added to \(S\); relaxing edges \((u,v)\) can only lower \(d[v]\).


d[s] ← 0
for each v ∈ V − {s}:
    d[v] ← +∞
S ← ∅
Q ← V    # priority queue keyed by d[·]
while Q ≠ ∅:
    u ← EXTRACT-MIN(Q)
    S ← S ∪ {u}
    for each v ∈ Adj[u]:
        if d[v] > d[u] + w(u, v):
            d[v] ← d[u] + w(u, v)

BELLMAN–FORD ALGORITHM

Computes single-source shortest paths on general weighted digraphs and detects negative-weight cycles reachable from the source.

STRATEGY

Dynamic programming by repeated relaxation of all edges. After \(|V|-1\) passes, all shortest paths with at most \(|V|-1\) edges are found if no negative-weight cycle is reachable.


d[s] ← 0
for each v ∈ V − {s}:
    d[v] ← +∞

for i ← 1 to |V| − 1:
    for each edge (u, v) ∈ E:
        if d[v] > d[u] + w(u, v):
            d[v] ← d[u] + w(u, v)

for each edge (u, v) ∈ E:
    if d[v] > d[u] + w(u, v):
        report "negative-weight cycle exists"

Relax all edges \(|V|-1\) times; distances converge in the absence of a reachable negative cycle.

DETECTING NEGATIVE-WEIGHT CYCLES

Corollary. If some \(d[v]\) can still be improved after \(|V|-1\) passes, then there exists a negative-weight cycle reachable from \(s\).
