QUESTION 1

RECURSIVE INSERTION SORT

  • Write insertion sort as a recursive algorithm.
  • Give the recurrence \(T(n)\) for the running time as a function of input size \(n\).

QUESTION 2

MERGE SORT TRACE

Given input array:


1, 0, 2, 6, 4, 5, 3, 8, 9, 7
  • After the two outermost recursive calls finish (just before the final Merge), view the two 5-element outputs as one glued 10-element array.
  • Which number is at the 7-th position?

QUESTION 3

TERNARY MERGE SORT

  • Modify merge sort to split into thirds, recursively sort each third, then use a three-way Merge.
  • What is the running time in terms of \(n\), ignoring constants and lower-order terms?
  • Provide explanation and working details.

QUESTION 4

SUCCESSIVE MERGING OF ARRAYS

  • You have \(k\) sorted arrays, each of length \(n\).
  • Merge linearly by repeatedly merging the running result with the next array using an \(O(n)\) subroutine.
  • What is the total running time as a function of \(k\) and \(n\) (ignore constants/lower-order terms)?
  • Provide explanation and working details.

QUESTION 5

PAIRWISE MERGE SCHEDULE

  • Group the \(k\) arrays into \(k/2\) pairs; merge each pair to get \(k/2\) arrays of length \(2n\).
  • Repeat until a single array of length \(kn\) remains.
  • What is the total running time as a function of \(k\) and \(n\) (ignore constants/lower-order terms)?
  • Provide explanation and working details.

QUESTION 6

CLOSEST PAIR OF POINTS

Goal: Find the pair of points with minimum Euclidean distance in 2D.

Input: \(P=\{(x_1,y_1),(x_2,y_2),\ldots,(x_n,y_n)\}\)

Output: a pair \((p_i,p_j)\) minimizing distance

\(\displaystyle \min_{i\ne j}\sqrt{((x_i-x_j)^2+(y_i-y_j)^2})\)

EXAMPLE

Input:


P = {(2, 3), (12, 30), (40, 50), (5, 1), (12, 10)}

Output: The closest pair is \((2,3)\) and \((5,1)\).

EXTRA QUESTION

TILING WITH L-SHAPED CARPETS

  • Room: \(2^k \times 2^k\) square, divided into \(2^{2k}\) unit cells.
  • Exactly one cell is already covered; all others are bare.
  • Tiles: \(2^{2k-1}\) L-shaped pieces, each covering 3 cells.
  • Goal: Tile all uncovered cells without overlap; rotations allowed; no cutting.

(A) ALGORITHM

  • Design a divide-and-conquer algorithm.
  • Input: \(n=2^k\) and coordinates \((x,y)\in\{1,\ldots,n\}\times\{1,\ldots,n\}\) of the missing square.
  • Output: A list of triples describing the positions of placed L-shaped tiles.
  • Provide: (i) concise English description (pictures welcome), (ii) clear pseudocode or readable Python.

(B) CORRECTNESS

  • Prove the algorithm correctly tiles all uncovered cells and respects constraints.

(C) RUNNING TIME

  • Give a recurrence for the worst-case running time in terms of \(n\).
  • Solve the recurrence and state the asymptotic running time.

(a) A carpet piece in one of its 4 possible orientations. (b) A \(16\times16\) floor with one covered cell.
