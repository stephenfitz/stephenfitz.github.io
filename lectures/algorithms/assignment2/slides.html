ALGORITHM 1


FindMax(A, l, r)
----------------
// Input: A is an array of real numbers, indexed 1..n
// l, r ∈ {1, …, n} with l ≤ r.
if l = r then
  return A[l]
else if r − l = 1 then
  return max(A[l], A[r])
else
  mid ← ⌊(l + r)/2⌋
  return max(FindMax(A, l, mid), FindMax(A, mid + 1, r))
end if
