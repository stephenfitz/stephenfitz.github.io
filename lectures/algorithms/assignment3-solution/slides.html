RecursiveInsertionSort(A, n)
  if n ≤ 1 then
    return
  RecursiveInsertionSort(A, n-1)
  key ← A[n]
  j ← n-1
  while j ≥ 0 and A[j] > key do
    A[j+1] ← A[j]
    j ← j-1
  A[j+1] ← key
end function

The recurrence relation is:

\(T(n) = T(n-1) + O(n)\)

SOLUTION 6

Strategy: Divide and Conquer

  1. Sort points by x-coordinate.
  2. Divide into two halves.
  3. Recursively solve in both halves.
  4. Merge: check strip around dividing line.

ClosestPair(P)
  divide P into left and right (half the set)
  δ1 ← ClosestPair(left)
  δ2 ← ClosestPair(right)
  δ ← min(δ1, δ2)
  filter points within δ of dividing line
  sort by y-coordinate
  compare distances in strip (update δ)
  return min distance δ
end function
  • Initial sorting: O(n log n)
  • Recurrence: T(n) = 2T(n/2) + O(n)
  • Solution: O(n log n)

EXTRA SOLUTION

STRATEGY

Recursive Idea:

  • Divide floor into 4 quadrants.
  • Place 1 tromino to ensure each quadrant has 1 missing square.
  • Recurse on each quadrant.

CORRECTNESS

Induction:

  • Base case: 1x1 grid is trivially correct.
  • Induction step: After tromino placement, all 4 subgrids have exactly one missing cell; recursive correctness ensures full tiling.

COMPLEXITY

Recurrence:

\(T(n) = 4T(n/2) + \Theta(1)\)

Solution:

\(T(n) = \Theta(n^2)\)
