THE DIVIDE-AND-CONQUER PARADIGM

Divide the problem into a number of subproblems that are smaller instances of the same problem.

Conquer the subproblems by solving them recursively. If the subproblem sizes are small enough, solve them directly.

Combine the solutions to the subproblems into the solution for the original problem.

MERGE SORT

Merge sort is a classic example of the divide-and-conquer approach.

  • Divide: We divide the $n$-element array to be sorted into two subarrays of $n/2$ elements each.
  • Conquer: We recursively sort the two subarrays. Arrays of size $1$ are already sorted, so we can return them directly.
  • Combine: We merge the two sorted subarrays to produce the sorted answer. This is done in linear time.

We can express the running time of a divide-and-conquer algorithm with a recurrence relation.

$$ T(n) = 2 T(n/2) + \Theta(n) $$
  • $2$: The number of subproblems we divide the main problem into.
  • $n/2$: The size of each subproblem.
  • $\Theta(n)$: The work required to divide the problem and combine the subproblem solutions.

The Master Theorem

The Master Theorem provides a "cookbook" method for solving recurrence relations of the form:

$$ T(n) = a T(n/b) + f(n) $$

where $a \ge 1$ and $b > 1$ are constants and $f(n)$ is an asymptotically positive function.

We compare $f(n)$ with $n^{\log_b a}$:

  1. If $f(n) = O(n^{\log_b a - \epsilon})$ for some constant $\epsilon > 0$, then $T(n) = \Theta(n^{\log_b a})$.
  2. If $f(n) = \Theta(n^{\log_b a} \lg^k n)$ for some constant $k \ge 0$, then $T(n) = \Theta(n^{\log_b a} \lg^{k+1} n)$.
  3. If $f(n) = \Omega(n^{\log_b a + \epsilon})$ for some constant $\epsilon > 0$, and if $a f(n/b) \le c f(n)$ for some constant $c < 1$ and all sufficiently large n, then $T(n) = \Theta(f(n))$.

For Merge Sort, the recurrence is $T(n) = 2 T(n/2) + \Theta(n)$.

  • $a = 2$ (subproblems)
  • $b = 2$ (input size reduction)
  • $f(n) = \Theta(n)$

First, we compute $n^{\log_b a} = n^{\log_2 2} = n^1 = n$.

Since $f(n) = \Theta(n)$, this matches Case 2 with $k=0$.

Therefore, the solution is $T(n) = \Theta(n \lg n)$.

BINARY SEARCH

THE PROBLEM

  • Problem: Find a target element within a sorted array.
  • Input: A sorted array and a target number.
  • Output: Return the index of the target if found, otherwise return -1.

A brute-force solution would be to scan the entire array, which takes linear time, $\Theta(n)$.

THE ALGORITHM

Binary search also follows the divide-and-conquer pattern:

  • Divide: Compare the target with the middle element of the array.
  • Conquer: If they are not equal, recursively search in one of the two subarrays (either the left half or the right half), discarding the other half.
  • Combine: The combine step is trivial, as the result from the recursive call is the final result.

example

Let's find the number 9 in the sorted array below.


						3  5  7  8  9  12  15

First, we check the middle element, which is 8.

Since 9 > 8, we search the right half.

We are now searching in the subarray:


						9  12  15

The new middle element is 12.

Since 9 < 12, we search the left half of this subarray.

We are now searching in the final subarray:


						9

The middle (and only) element is 9.

The target is found!

PSEUDOCODE IMPLEMENTATION

Here is a recursive implementation of the binary search algorithm.


BinarySearch(A, x, left, right)
-------------------------------
if left > right then
    return -1 // Base case: target not found

mid <- floor((left + right) / 2)

if A[mid] = x then
    return mid // Base case: target found
else if A[mid] < x then
    return BinarySearch(A, x, mid + 1, right)
else
    return BinarySearch(A, x, left, mid - 1)

COMPLEXITY ANALYSIS

The recurrence relation for binary search is:

$$ T(n) = 1 T(n/2) + \Theta(1) $$
  • $1$: We make one recursive call.
  • $n/2$: The subproblem is half the size of the original.
  • $\Theta(1)$: The work to find the midpoint and compare is constant time.

Using the Master Theorem (Case 2), this solves to $T(n) = \Theta(\lg n)$.

NATURAL POWER

PROBLEM

Compute $a^n$, where $n$ is a natural number.

NAIVE ALGORITHM

Multiply $a$ by itself $n-1$ times. This takes $\Theta(n)$ time.

We can do much better with the divide-and-conquer strategy.

DIVIDE AND CONQUER APPROACH

The key is to use the properties of exponents:

$$ a^n = \begin{cases} a^{n/2} \cdot a^{n/2} & \text{if n is even} \\ a^{(n-1)/2} \cdot a^{(n-1)/2} \cdot a & \text{if n is odd} \end{cases} $$

Notice we only need to compute the recursive term once.

COMPLEXITY ANALYSIS

This approach leads to the recurrence relation:

$$ T(n) = T(n/2) + \Theta(1) $$

This is because we solve one subproblem of half the size and do a constant number of multiplications to combine the result.

This is the same recurrence as binary search. The solution is $T(n) = \Theta(\lg n)$.
