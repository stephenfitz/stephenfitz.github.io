QUESTION 1

Connected Components

You are given an undirected graph with n nodes labeled from 1 to n and a list of edges where each edge connects two nodes.

A connected component in the graph is a set of nodes such that:

  • Any two nodes in the set are connected directly or indirectly by edges.
  • No node in the set is connected to a node outside the set.

Your task: write a function to return the number of connected components in the graph.

Example input:

n = 5
edges = [[1, 2], [2, 3], [4, 5]]

Corresponding output:

2

Explanation: the graph has two connected components: {1, 2, 3} and {4, 5}.

QUESTION 2

Cycle Detection in an Undirected Graph

You are given an undirected graph with n vertices labeled from 1 to n, represented as an adjacency list.

Your task is to determine whether the graph contains a cycle.

The function should return true if there exists at least one cycle in the graph, and false otherwise.

Example input:

n = 5
E = [(0, 1), (1, 2), (2, 0), (3, 4)]

Corresponding output:

True

Explanation: the cycle is 0 → 1 → 2 → 0.

QUESTION 3

Cheapest Flight with Limited Stops

You are given a list of flights, where each flight is represented as a triplet (u, v, w), indicating that there is a flight from city u to city v with a cost of w.

Your task is to compute the minimum cost to travel from src to dst with at most K stops (that is, up to K + 1 flights).

If no such route exists, return −1.

The inputs are:

  • An integer n — the total number of cities, labeled from 0 to n − 1.
  • A list of flights F = [(u₁, v₁, w₁), …, (uₘ, vₘ, wₘ)].
  • A source city src.
  • A destination city dst.
  • An integer K — the maximum number of allowed stops.

Example input:

n = 4
flights = [(0, 1, 100), (1, 2, 100), (2, 3, 100), (0, 2, 500)]
src = 0
dst = 3
K = 1

Corresponding output:

600

Explanation:

  • The path 0 → 2 → 3 has total cost 600 and uses only 1 stop, so it is valid.
  • The cheaper path 0 → 1 → 2 → 3 has cost 300 but uses 2 stops, which exceeds the allowed limit.

Hint

This problem is a variation of the shortest path problem with a constraint on the number of stops.

You can solve it using a modified version of Dijkstra’s algorithm or a layered Bellman–Ford approach that accounts for the maximum number of edges (flights) used.

EXTRA QUESTION

Course Scheduling with Prerequisites

You are given a total of numCourses courses labeled from 1 to numCourses.

You are also given a list of prerequisite pairs prerequisites, where each pair [a, b] indicates that to take course a, you must first take course b.

Write a function that returns true if it is possible to finish all courses; otherwise, return false.

Example input:

numCourses = 2
prerequisites = [[1, 0]]

Corresponding output:

true

Example input:

numCourses = 2
prerequisites = [[1, 0], [0, 1]]

Corresponding output:

false

Hint

This problem reduces to detecting a cycle in a directed graph.

If the prerequisite graph has a cycle, it is impossible to complete all courses; if the graph is acyclic, then a valid ordering exists and all courses can be finished.
