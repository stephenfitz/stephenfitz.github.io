Machine learning and neural networks for energy applications

Two instructor-led courses of five full teaching days each (09:00–17:00), with slides, worked examples, classroom exercises, hands-on laboratories and complete instructor notes.

  • Machine learning for energy applications: supervised learning; ensembles and interpretation; clustering; dimensionality reduction and feature selection; rare events, anomalies and model selection.
  • Neural networks for energy applications: neural network foundations; training networks reliably; an energy modelling capstone; convolutional networks; sequence models and attention.

The ten decks contain 897 slides and 401 figures and diagrams. Every slide has instructor notes with timings, full answers to every exercise with the arithmetic behind them, common misconceptions and transitions. Every laboratory has a student notebook and a worked solution.

Start here

  • index.html: open it in a browser for every deck (HTML, PDF, PowerPoint), the exercise notebooks and their solutions, the guides and each module's instructor notes as web pages; it works offline.
  • Instructor guide: day plans, laboratory preparation, presenting, assessment, and the evaluation practice the courses teach.
  • Complete courses in one file each, with bookmarks: Machine learning · Neural networks.

Presenting

Open slides.html in any current browser; it works offline. Keep the notes panel closed while learners work, because the notes contain answers. With a second screen, press P and move the presenter window to your own display. The PowerPoint copy offers PowerPoint's presenter view with the same notes. To change content, edit slides.md and rebuild (below); the PowerPoint file is generated.

Laboratories

Create a dedicated Python environment (3.11 or 3.12) and run the preflight check before class:

python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-labs.txt            # all core laboratories
pip install -r requirements-labs-optional.txt   # optional: UMAP, XGBoost, imbalanced-learn
python3 curriculum/preflight.py

Some laboratories download public datasets on first use (California housing, MNIST, CIFAR-10, SVHN). On classroom machines, download them beforehand into a shared folder and set COURSE_DATA to it. The instructor guide lists every laboratory's notebook, solution runtime and preparation.

Editing and rebuilding

The decks are generated from the Markdown sources and the Python figure code; no output file is edited by hand.

pip install -r requirements-slides.txt
python3 curriculum/make_figures.py            # regenerate all figures (5–15 minutes)
python3 curriculum/make_figures.py --only ml3 # or one module's figures (keys ml1–ml5, nn1–nn5)
python3 render_slides.py --all                # rebuild every deck and the combined PDFs
python3 curriculum/build.py <path>/slides.md  # or one deck
python3 curriculum/build_site.py              # rebuild index.html and the HTML pages in site/
python3 curriculum/verify.py                  # structural and numerical checks

curriculum/AUTHORING.md documents the slide syntax, layouts, figure toolkit and editorial standards; curriculum/layout_reference/slides.pdf shows every layout, and its source slides.md in the same folder shows how each one is written. Figures are generated by curriculum/figs/<module>.py into curriculum/figures (vector PDF used by the decks, plus SVG and PNG), with the provenance of each figure recorded in curriculum/figures/manifest.json. Rebuilding unchanged sources reproduces identical files.
